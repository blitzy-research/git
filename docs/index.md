# Git

Git is a fast, scalable, distributed revision control system with an unusually rich command set that provides both high-level operations and full access to internals.

This site is a Markdown-friendly entry point for the Blitzy fork of Git. The authoritative reference manual lives in the upstream repository as AsciiDoc files under `Documentation/` (e.g. `gittutorial.adoc`, `giteveryday.adoc`, and per-command `git-<commandname>.adoc`). Those files are rendered by the upstream build pipeline into man pages and HTML — they cannot be rendered directly here, because TechDocs only supports Markdown.

## Where to go next

- **Installation** — see [Setup](setup.md) for a summary of the install instructions adapted from the repository `INSTALL` file.
- **Upstream reference** — <https://git-scm.com/docs>
- **AsciiDoc source** — see the `Documentation/` folder in this repository for the full reference tree (`gittutorial.adoc`, `giteveryday.adoc`, individual `git-*.adoc` pages).

## Name

"Git" is the name of the original author, and is a stable, well-known name. It is also the British slang for "an unpleasant person", which the author considers an apt description.
